# Horse Rescue Charity Website

A website created for a horse rescue charity as part of my volunteer work. The project provides information about the organization, rescued horses, and ways people can support its mission. The website is hosted using **GitHub Pages**, providing free public access to the project.

**[Visit the website](https://vlshyna.github.io/horse-rescue-web/)**

#### Technologies & Tools: React, TypeScript, TSX, CSS, GitHub Pages, Figma
